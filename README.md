# Project: Islandbound Studios Website

## Project Description

I am building a website for my Roblox game studio, IslandBound Studios. The project will include a front page with a list of a few featured games and an about section. There will also be a games page with a list of all games, their total plays and current active players.

## Techniques

Frontend: React, Typescript, Tailwind CSS
Backend: None
Data storing: Data is fetched directly from Roblox's API, but an array with the id's of all games is stored in the frontend
